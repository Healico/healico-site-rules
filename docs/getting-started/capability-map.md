# 能力边界与学习路线

## 直接回答

当前文档覆盖通用站点规则的主干：列表、搜索、详情、章节、图片分页、JSONPath / CSS 选择器、URL 模板、请求头和本地测试。

它也完整说明高级协议字段，但高级协议仍建议先通过本地模拟接口练习，不要直接对真实站点试错。

## 按站点类型判断

| 站点类型 | 当前文档是否足够 |
| --- | --- |
| 普通公开 JSON API | 足够入门 |
| 普通 HTML 页面 | 足够入门，建议多做 HTML 练习 |
| 固定公开请求头 | 足够 |
| 请求签名或时间戳 | 需要先学习 `requestProfile.steps` |
| 响应解码或解密 | 需要先学习 `responseSteps` |
| 客户端渲染页面 | 需要先学习 `webDom` |
| 账号登录 | 不应把凭据写入规则 |
| 验证码、付费墙或访问控制 | 不支持绕过 |

## 学习路线

1. **Level 1：普通 JSON API**  
   列表、详情、章节、图片。
2. **Level 2：HTML + CSS**  
   页面结构、属性回退、相对链接。
3. **Level 3：分页与网络**  
   页码、偏移分页、请求头、镜像、错误处理。
4. **Level 4：协议步骤**  
   本地模拟签名、编码、响应转换。
5. **Level 5：浏览器与媒体**  
   `webDom`、浏览器脚本、图片密文、播放器参数。
