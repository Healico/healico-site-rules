请求协议配置：requestProfile

requestProfile 描述通用请求管线：基础地址、公开协议参数、请求前计算、响应后处理、状态、恢复和缓存。它只描述协议，不应包含个人凭据。

顶层字段

字段说明
publicParameters作者公开的协议常量；最多 32 项，值必须是字符串且不超过 256 字符。
transport请求传输配置。
baseUrl协议基础地址。
forceBase是否强制使用基础地址。
domains允许的协议主机列表。
headers协议层请求头。
steps请求前值计算步骤。
responseSteps响应后处理步骤。
state状态字段声明。
initializeUrl / initializeHeaders初始化请求。
credentialOrigins可携带私有请求头的 HTTPS origin。
retry协议错误恢复。
auxiliaryToken辅助公开令牌状态。
queryDefaults默认查询参数。
successCodePath / successCode成功码判断。
cacheTtlMs / galleryCacheTtlMs / cacheMaxEntries / cacheIgnoreQuery缓存策略。
serial是否串行执行请求。
account账号流程描述。
readFallback特定读取路径的独立回退。

公开参数限制

publicParameters 的键必须是合法标识符，不能使用保留名或凭据相关名称，例如 token、cookie、authorization、password、secret、session、signature、device 等。值不能包含大括号、换行或回车。

安全边界：公开参数只放协议本身的无害常量；用户令牌、账号状态和设备身份不能写进可分享规则。

状态字段

"state": [
  {
    "name": "layout",
    "initial": "default",
    "label": "布局",
    "options": ["default", "compact"],
    "optionLabels": ["默认", "紧凑"],
    "resettable": true
  }
]

状态字段用于公开协议选项。它不能伪装成用户凭据，也不能让持久化状态覆盖作者声明的公开参数。

ValueStep 通用结构

{
  "op": "hmac",
  "out": "signature",
  "input": "path={{path}}×tamp={{timestamp}}",
  "key": "public-demo-key",
  "algorithm": "SHA256",
  "encoding": "utf8"
}
属性说明
op操作类型。
out输出变量名；必须是合法标识符。
input输入模板；支持 {{name}}。
key / iv密钥或初始向量模板。
encodingutf8、base64、hex。
algorithm哈希 / HMAC / AES 算法。
flags正则 flags。
pattern / replacement正则匹配或替换。
start / end切片范围。
pathJSONPath。
fallback正则失败时的回退模板。

支持的 ValueStep 操作

op行为
template只展开 {{name}} 模板。
hash计算摘要并输出十六进制；默认 MD5。
hmac计算 HMAC；默认 SHA256，输出十六进制。
base64UTF-8 字符串转 Base64。
slice按 start / end 截取字符串。
regex执行正则；命中取捕获组或整个匹配。
replace全局正则替换。
json从 JSON 输入中读取 JSONPath。
aesAES 解密；支持 CBC 和 ECB 兼容模式。
jsonBoundary从文本中截取第一个 JSON 对象或数组并校验。
zipSort按 key 字符顺序重排 input 字符。
random按模式生成随机值：d 数字、D 非零数字、A 大写、x 字母数字。
authorization拼接 scheme value 形式的 Authorization 头值。

步骤按数组顺序执行；后续步骤可引用前面 out 变量。必需步骤失败时请求失败，不应静默回退到不可验证的数据。

域名发现

"discovery": {
  "url": "https://discover.example.test/hosts",
  "steps": [
    { "op": "json", "input": "{{body}}", "path": "$.hosts", "out": "body" }
  ],
  "path": "$.hosts",
  "maxHosts": 5
}

discovery 只在需要显式声明可用主机时使用。它不是绕过访问控制的机制。

错误恢复

"retry": {
  "codes": [429, 503],
  "codePath": "$.code",
  "maxAttempts": 3,
  "recoveryUrl": "https://reader.example.test/recover"
}

retry 描述有限次数、明确条件的恢复。不能创建无限重试，也不能把 401、403、验证码或付费墙当作可自动绕过的状态。

辅助令牌

auxiliaryToken 包含 state、equals、url、path、query、ttlMs、fallback。它只描述公开协议状态，不能保存用户凭据。

账号配置

account 包含 enabled、url、steps、body、headers、tokenPath、messagePath、tokenState。账号令牌属于当前用户和设备，不应写入可分享 JSON。

读取回退

"readFallback": {
  "origin": "https://backup.example.test",
  "pathPattern": "^/api/chapters/[^/]+/images$",
  "queryParameters": ["page"],
  "headers": { "Accept": "application/json" }
}

readFallback 只在传输或服务器失败时使用，必须声明规范 HTTPS origin、完整路径正则、查询参数白名单和独立请求头。
