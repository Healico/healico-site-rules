核心数据流

indexUrl ──► indexRule ──► idCode
searchUrl ─► searchRule ─► idCode
                         │
detailUrl ◄──────────────┘
   │
   └─► detailRule ──► chapterRule / chaptersApi ──► cidCode
                                                    │
galleryUrl ◄────────────────────────────────────────┘
   │
   └─► galleryRule ──► image / video

先让每一阶段独立可验证，再组合成完整规则。不要在列表未通过时直接编写图片规则。
