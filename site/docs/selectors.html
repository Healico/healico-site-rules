选择器参考

选择器负责把响应内容转换成字段值。JSON 响应使用 JSONPath；HTML 响应使用 CSS 选择器。

Selector 对象

属性类型作用
selectorstringJSONPath、CSS 选择器或 this。
functionstring提取函数：text、attr、html；支持逗号备选和点号变换链。
paramstringattr 的属性名；支持逗号回退。
regexstring对提取结果执行正则匹配。
replacementstring重组结果；$1–$9 引用捕获组。

JSONPath 子集

支持：

  • $：根对象或根数组
  • $.field：字段
  • $['field']：带特殊字符的字段
  • $.items[0].name：数组下标

不支持通配符、过滤表达式和递归下降。选择器指向数组时，作为 item 会自动迭代。

{
  "item": { "selector": "$.payload.books" },
  "idCode": { "selector": "$.key" },
  "title": { "selector": "$.label" },
  "cover": { "selector": "$.cover" },
  "nextPageUrl": { "selector": "$.links.next" }
}
层级规则：item 与响应级字段从根对象求值；条目字段从每个数组元素求值。

CSS 模式

当 selector 不以 $. 开头时按 CSS 处理。多个选择器可用逗号分隔，首个命中生效；:not(...) 内的逗号会受到保护。

{
  "item": { "selector": "main .book" },
  "idCode": { "selector": "[data-key]", "function": "attr", "param": "data-key" },
  "title": { "selector": "h2", "function": "text" },
  "cover": { "selector": "img", "function": "attr", "param": "data-src, src" }
}

this 表示当前条目本身，常用于字符串数组：

{
  "item": { "selector": "$" },
  "image": { "selector": "this" }
}

函数与变换

写法行为
text提取文本；缺省或未知函数也按文本处理。
attr提取属性，需要 param。
html提取内部 HTML，常用于脚本内容。
text, attr依次尝试，首个非空结果生效。
attr.decodeBase64先取属性，再 Base64 解码。
text.reversed先取文本，再反转字符串。

param 支持 textContent、innerText、text 伪属性，以及 data-src, src 这类回退链。

正则与替换

{
  "selector": "$.label",
  "function": "text",
  "regex": "第(\\d+)话",
  "replacement": "第 $1 章"
}
  • 没有 replacement 时：有捕获组取第一个捕获组；没有捕获组取整个匹配。
  • 有 replacement 时：用 $1–$9 引用捕获组。
  • 替换模板还支持运行时占位符，如 {source:}。
  • 正则不匹配时字段为空。

排错顺序

  1. 确认响应确实是 JSON 或 HTML。
  2. 先测 item，确保命中数量正确。
  3. 再测 idCode 和 title。
  4. 最后加封面、日期、评分等非关键字段。
