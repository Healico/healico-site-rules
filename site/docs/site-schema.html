站点结构与顶层字段

一条 Healico 站点规则是一个 JSON 对象。顶层字段描述“请求哪里、用什么请求头、显示方式是什么、每个阶段如何解析”。

最小结构

{
  "name": "本地示例",
  "domain": "reader.example.test",
  "indexUrl": "https://reader.example.test/api/books?page={page:1}",
  "indexRule": {
    "item": { "selector": "$.payload.books" },
    "idCode": { "selector": "$.key" },
    "title": { "selector": "$.label" },
    "cover": { "selector": "$.cover" },
    "nextPageUrl": { "selector": "$.links.next" }
  }
}

name、domain、indexUrl 和 indexRule 是入门阶段的最小组合。搜索、详情和章节应在列表验证通过后逐项添加。

入口地址

字段作用说明
indexUrl列表入口必填；通常包含 {page:1}。
searchUrl搜索入口通常包含 {keyword:} 与页码。
detailUrl详情入口通常由 {idCode:} 生成。
galleryUrl章节图片入口通常由 {cidCode:} 生成。
webUrl人类可读页面当详情入口是 JSON API 时，可另行提供原页面地址。
seriesUrl系列入口用于系列或合集数据。
tagUrl标签入口配合 tagSearchRule。
loginUrl登录页面只描述入口；不要把凭据写进规则。

请求头

公共请求头写在 httpHeaders；阶段请求头覆盖同名公共字段：

字段阶段
indexHTTPHeaders列表
searchHTTPHeaders搜索
detailHTTPHeaders详情与章节接口
galleryHTTPHeaders章节图片页
imageHTTPHeaders图片请求
videoHTTPHeaders视频请求
禁止硬编码凭据：不要在可分享规则里写 Cookie、Authorization、Token、密码、签名密钥或设备身份。公开协议参数使用 requestProfile.publicParameters，用户状态由应用内账号流程处理。

解析规则

字段作用
indexRule解析列表响应
searchRule解析搜索响应；缺省时可回退列表规则
detailRule解析详情、章节入口和元数据
galleryRule解析章节图片或视频
seriesRule解析系列数据
tagSearchRule解析标签搜索数据
extraRule扩展数据容器

页面配置

pages 是对象数组，用于同一个站点内的多个分类页：

"pages": [
  {
    "name": "最近更新",
    "indexUrl": "/api/latest?page={page:1}",
    "listRule": { "item": { "selector": "$.items" } },
    "detailRule": { "title": { "selector": "$.title" } },
    "galleryRule": { "image": { "selector": "$.url" } }
  }
]

页面级字段包括 name、displayMode、indexUrl、detailUrlPattern、galleryUrlPattern、flags、listRule、detailRule、galleryRule。

图片与网络选项

字段说明
imageTransport图片传输策略；默认 rcp。
imageHeaderModemerge 合并调用方与站点请求头；replace 只使用配置的图片请求头。
imageHostPatterns图片主机匹配正则数组；应加首尾锚点。
mirrors备用主机映射，如 {"reader.example.test":["backup.example.test"]}。
credentialOrigins显式声明可携带私有请求头的 HTTPS origin；仍不得硬编码凭据。

展示与元数据

字段说明
displayMode站点或页面的展示模式。
chapterOrder章节顺序，常见值 asc、desc。
galleryDirection阅读方向，如 vertical、horizonal、horizonal.RTL。
imagePairingMode双页拼合模式，如 none、pair12、pair23。
flags兼容展示标记字符串。
version / author / authorWebsite / icon规则版本与作者信息。
throttleBudget每个任务的章节请求预算。

完整骨架

{
  "name": "完整骨架示例",
  "domain": "reader.example.test",
  "version": "1",
  "indexUrl": "https://reader.example.test/api/books?page={page:1}",
  "searchUrl": "https://reader.example.test/api/search?q={keyword:}&page={page:1}",
  "detailUrl": "https://reader.example.test/api/books/{idCode:}",
  "galleryUrl": "https://reader.example.test/api/chapters/{cidCode:}/images?page={page:1}",
  "httpHeaders": { "Accept": "application/json" },
  "indexRule": {},
  "searchRule": {},
  "detailRule": {},
  "galleryRule": {},
  "requestProfile": {},
  "pages": []
}

空对象只用于展示位置；实际规则应删除未使用字段，避免误以为它们已配置。
