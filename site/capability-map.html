学完这个站，能写哪类 Healico 站点规则？

2026-09-19 · 能力边界说明

直接回答：当前教程覆盖的是通用站点规则的主干：列表、搜索、详情、章节、图片分页、JSONPath / CSS 选择器、URL 模板、请求头和本地测试。它能帮助你写出结构清晰的普通 JSON / HTML 站点规则，但还不是 Healico 规则引擎的完整教材，也没有手把手讲解签名请求、加密响应、浏览器脚本、播放器参数和账号状态等高级能力。

按站点类型判断：你现在能不能写？

站点类型学完当前教程后说明
普通公开 JSON API可以开始写列表、详情、章节、图片结构清楚时，当前教程足够入门。
普通 HTML 页面可以看懂并尝试需要再补一轮纯 HTML 实战练习。
需要固定公开请求头可以写只放公开协商字段，不放凭据。
需要请求签名或时间戳暂时不能只靠本站需要 requestProfile.steps 高级课程。
响应需要解密或解码暂时不能只靠本站需要 responseSteps 高级课程。
客户端渲染页面暂时不能只靠本站需要 webDom 与就绪标记课程。
需要账号登录不建议写进分享规则凭据必须由应用账号流程处理，不能硬编码到 JSON。
需要绕过验证码、付费墙或访问控制不能写本教程不提供也不支持这类规则。

建议补齐的学习路线

Level 1普通 JSON API：列表 / 详情 / 章节 / 图片
Level 2HTML + CSS：真实页面结构与属性回退
Level 3分页策略、镜像、请求头与错误处理
Level 4本地模拟签名 API 与 responseSteps
Level 5webDom、浏览器脚本与媒体播放器

高级课程也应该继续使用本地模拟接口：先在本地生成签名、返回加密或打乱的数据，再让规则一步步还原。这样能学到协议能力，又不需要引用真实站点或携带任何凭据。
